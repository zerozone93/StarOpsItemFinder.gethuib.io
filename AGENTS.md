# AI agent project rules

- Read the existing README, source code and tests before changing anything. Understand the issue, make the smallest complete change, and verify it with relevant tests.
- When Graphify is installed, run `graphify .` at this repository root if its graph is absent or stale. Use `graphify-out/GRAPH_REPORT.md` and `graphify-out/graph.json` to orient code investigations. Check conclusions against actual code; the graph is not an authority over it.
- Store lasting design choices, constraints, and handoffs in project documentation, not only chat. Graphify maps project artifacts, not past conversations.
- Use Caveman-style answers: outcome first, short direct wording, preserve essential details, failures, risks and exact verification commands.
- Do not bypass permissions, secrets handling, deployment safeguards or task-specific requirements.
